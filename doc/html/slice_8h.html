详细描述

非持有型字符序列视图类定义，提供安全、高效的字符串操作接口（兼容C++11）

该类是一个非持有型的字符序列视图，类似C++17的std::string_view，但兼容C++11标准。核心特性包括：

  1. 内存安全：严格的空指针校验，所有构造和操作均避免空指针访问，抛出明确的异常；
  2. 高效操作：不管理内存，仅持有外部字符序列的指针，所有操作均为O(1)或O(n)时间复杂度，无额外内存分配；
  3. 丰富接口：提供字符串常见操作，如查找（find）、截取（sub）、吞噬（eat）、分割（split）、前后空白修剪（trimSpace）等；
  4. 兼容性强：支持从std::string、C风格字符串、指针+长度等多种方式构造，可隐式转换为std::string；
  5. 线程安全说明：成员函数均为const/无状态操作，多线程只读访问安全；若需多线程修改（如eat/trimSpace），需外部加锁。
    注解
  1. 生命周期管理：由于不持有内存，需确保外部字符序列的生命周期长于Slice对象，避免悬垂指针；
  2. 异常处理：非法操作（如越界访问、空指针构造）会抛出std::invalid_argument或std::out_of_range异常，需上层捕获处理；
  3. 字符编码：默认处理ASCII字符，若需支持多字节编码（如UTF-8），需自行确保操作的正确性（如trimSpace仅处理空格、制表符等ASCII空白字符）；
  4. 性能优化：所有接口均经过优化，避免不必要的计算和内存拷贝，适合高并发、高性能场景。
