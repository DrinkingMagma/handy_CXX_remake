详细描述

系统错误处理与状态封装工具类，提供线程安全的错误信息管理和统一的状态表示

该文件包含两个核心功能模块：

  1. 线程安全的错误信息获取（errstr函数）：
    • 封装strerror_r，使用线程局部存储（thread_local）避免多线程竞争；
    • 自动适配POSIX和XSI标准的strerror_r返回值差异，确保跨平台兼容性；
  2. 通用状态封装类（Status）：
    • 统一表示操作结果，包含状态码（0表示成功）和错误描述信息；
    • 支持拷贝/移动语义，通过深拷贝确保状态信息的独立性；
    • 提供丰富的静态工厂方法，如从系统错误（errno）创建、格式化错误信息创建、I/O错误专用创建等；
    • 提供简洁的接口获取状态码（code()）和错误信息（msg()），以及判断操作是否成功（ok()）。
      注解
  1. 线程安全：errstr函数和Status类的所有方法均为线程安全设计，可在多线程环境中放心使用；
  2. 内存管理：Status类通过动态分配内存存储状态信息，自动在析构函数中释放，避免内存泄漏；
  3. 跨平台兼容：针对strerror_r的不同标准实现进行适配，支持Linux、macOS等主流POSIX系统；
  4. 使用建议：推荐在所有需要返回操作结果的场景中使用Status类，替代直接返回错误码或抛出异常，使错误处理更统一、清晰。
