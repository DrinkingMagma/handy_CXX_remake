线程安全队列（SafeQueue）与线程池（ThreadPool）的接口定义

该文件提供了两个核心组件的接口：

  1. 线程安全队列（SafeQueue）：
    • 模板类，支持泛型元素存储，基于std::list实现；
    • 提供线程安全的入队（push）、出队等待（popWait）操作；
    • 支持容量限制、超时等待、优雅退出等功能；
    • 通过互斥锁（std::mutex）和条件变量（std::condition_variable）保证线程同步。
  2. 线程池（ThreadPool）：
    • 管理一组工作线程，基于SafeQueue实现任务队列；
    • 支持线程池启动（start）、退出（exit）、等待（join）等生命周期管理；
    • 提供任务添加接口（addTask），支持右值引用和左值引用传递任务；
    • 工作线程循环从任务队列获取任务并执行，捕获任务异常避免线程崩溃。
      注解
  1. 线程安全：所有公共接口均保证线程安全，可在多线程环境中并发调用；
  2. 任务类型：任务需是可调用对象（符合std::function<void()>签名），无返回值；
  3. 生命周期管理：线程池需先启动（start）后才能添加任务，退出（exit）后不再接受新任务，已入队任务会继续执行；
  4. 异常处理：工作线程会捕获任务执行过程中的所有异常，并记录错误日志，确保线程池稳定运行；
  5. 禁止拷贝：SafeQueue和ThreadPool均继承自NonCopyAble，禁止拷贝和移动操作，避免线程安全风险。
