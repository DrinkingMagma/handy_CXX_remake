详细描述

UDP服务器、客户端连接及HSHAU（Half-Sync/Half-Async UDP）模式的实现

该文件包含三个核心组件的实现：

  1. UdpServer：UDP服务器类，支持绑定地址、接收数据和发送数据；
    • 基于事件驱动模型，通过Channel监听读事件；
    • 支持地址复用和端口复用，非阻塞模式运行；
    • 接收数据时通过回调函数通知上层处理。
  2. UdpConn：UDP客户端连接类，支持与目标服务器建立连接、发送和接收数据；
    • 自动处理非阻塞连接逻辑，通过Channel监听读事件；
    • 提供简洁的发送接口，支持多种数据类型（char*、Buffer、std::string）。
  3. HSHAU：Half-Sync/Half-Async UDP模式实现，结合线程池处理耗时任务；
    • 同步层：事件循环线程负责接收和发送数据；
    • 异步层：线程池处理耗时的业务逻辑，避免阻塞事件循环；
    • 通过回调函数将业务处理结果返回给事件循环线程发送。
      注解
  1. 事件驱动：依赖EventBase和Channel实现事件监听和分发；
  2. 非阻塞IO：所有套接字均设置为非阻塞模式，避免IO操作阻塞线程；
  3. 线程安全：HSHAU模式下，业务逻辑在线程池执行，需确保回调函数线程安全；
  4. 错误处理：完善的错误日志记录，包括套接字创建、绑定、发送、接收等失败场景；
  5. 资源管理：自动管理套接字和Channel资源，避免内存泄漏。
