详细描述

通用工具函数实现，提供字符串格式化、时间处理、类型转换、文件描述符操作及MIME类型映射等基础功能

该文件实现了Utils类的核心静态方法，涵盖多个常用工具函数：

  1. 字符串格式化：format函数支持可变参数，自动扩容缓冲区，确保线程安全和内存安全；
  2. 时间处理：
    • timeMicro：获取系统时间戳（微秒级），基于system_clock；
    • steadyMicro：获取稳定时间戳（微秒级），基于steady_clock，适合计时；
    • readableTime：将time_t转换为人类可读的时间字符串，使用线程局部存储（TLS）避免多线程竞争；
  3. 类型转换：atoi和atoi2函数实现字符串到int64_t的转换，后者严格校验输入完整性；
  4. 文件描述符操作：addFdFlag函数安全添加文件描述符标志（如FD_CLOEXEC），避免重复设置；
  5. MIME类型映射：getMimeMap提供预定义的文件扩展名到MIME类型的映射，getMimeType根据文件名获取对应MIME类型。
    注解
  1. 线程安全：所有函数均设计为线程安全，时间处理使用TLS存储tm结构，避免全局变量竞争；
  2. 异常处理：关键函数（如时间转换、格式化）包含异常捕获，确保程序稳定性；
  3. 内存管理：使用智能指针（unique_ptr）管理动态缓冲区，避免内存泄漏；
  4. 参数校验：严格校验输入参数合法性（如文件描述符、字符串指针），增强函数鲁棒性；
  5. 跨平台兼容：依赖C++11及以上标准，使用标准库函数确保跨平台可用性。
